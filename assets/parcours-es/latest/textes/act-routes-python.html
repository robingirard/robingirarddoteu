Le moteur de l'outil « routes » en Python

Télécharger le moteur public de l'outil « ce que coûte chaque route » (un fichier Python et neuf fichiers d'hypothèses), tracer le prix du CO₂ qui fait basculer l'acier vers l'hydrogène en fonction du prix de l'électricité, puis refaire les prix de bascule que le cas H calcule aux tarifs des jeux de prix publiés, et changer une hypothèse.

Objectif : passer du curseur au calcul. L'outil web Décarbonation de l'industrie — ce que coûte chaque route (46 routes, 8 produits) fait tourner un petit moteur, écrit deux fois (JavaScript pour la page, Python pour les calculs), vérifiés identiques sur les 46 routes. Le moteur Python est public. La partie A (N1, 35 min) trace une courbe de bascule ; la partie B (N2, 45 min) refait ce que fait le cas H avant de lancer son modèle. Il faut Python avec pyyaml et matplotlib (pip install pyyaml matplotlib). Valeurs du 18/11/2026, moteur v2.1 (10/10/2026).

Partie A (N1). Le prix de l'électricité qui fait basculer l'acier

Un prix de bascule est le prix du CO₂ à partir duquel une route bas carbone coûte moins cher que la route de référence (ici le haut fourneau, BF-BOF), en comptant ce que chacune paie de quota. Le DRI-H₂ (fer réduit à l'hydrogène, puis four électrique) achète son hydrogène, donc son électricité : son prix de bascule dépend du prix de l'électricité.

  1. Télécharger le moteur et ses hypothèses (les cinq premières lignes du bloc), puis vérifier qu'on retrouve l'onglet Acier : BF-BOF 523 €/t, DRI-H₂ 772 €/t.
  2. Faire varier l'électricité de 10 à 150 €/MWh et tracer le prix de bascule du DRI-H₂. Constater que c'est une droite, et lire sa pente.
  3. En déduire le prix de l'électricité qui ramène la bascule à 100 €/tCO₂.
  4. Par dichotomie : avec un quota à 300 €/t, sous quel prix de l'électricité le DRI-H₂ coûte-t-il moins que le haut fourneau avec captage du CO₂ (BF-BOF + CCS) ?
  5. Vérifier un point dans le navigateur : électricité à 30 €/MWh, onglet Acier, figure « Coût d'abattement contre la route de référence (BF-BOF) ». Le prix de bascule n'y est écrit que dans l'infobulle du petit triangle noir posé sur la barre du DRI-H₂ (survoler à la souris) : 129 €/tCO₂. Deux pièges : la barre elle-même donne le coût d'abattement (127), et la vignette « Prix du quota qui fait basculer » parle d'une autre route (le recyclage).
import sys, pathlib, urllib.request
BASE = "https://git.persee.minesparis.psl.eu/energy-alternatives/industry_decarbo_routes/-/raw/main/"
for f in ["modele.py"] + [f"hypotheses/{n}.yaml" for n in "commun hydrogene acier ciment ammoniac methanol olefines aluminium saf".split()]:
    (pathlib.Path("idr") / f).parent.mkdir(parents=True, exist_ok=True)
    urllib.request.urlretrieve(BASE + f, pathlib.Path("idr") / f)
sys.path.insert(0, "idr"); import modele
import matplotlib.pyplot as plt
hyp = modele.charger()
def acier(elec=70, co2=70):                                     # €/MWh, €/tCO2 ; le reste par défaut
    etat = modele.etat_defaut(hyp)
    etat["prix"]["electricite"], etat["prix"]["co2_ets"] = elec, co2
    return modele.calculer_produit(hyp, etat, "steel")["routes"]
r = acier()
print("BF-BOF", round(r["bf_bof"]["cout_total"], 1), "| DRI-H2", round(r["dri_h2_eaf"]["cout_total"], 1),
      "€/t | bascule DRI-H2", round(r["dri_h2_eaf"]["prix_co2_bascule"], 1), "€/tCO2")
prix = range(10, 151, 10)
bascule = [acier(p)["dri_h2_eaf"]["prix_co2_bascule"] for p in prix]
pente = (bascule[-1] - bascule[0]) / (prix[-1] - prix[0])        # la courbe est une droite
print("pente", round(pente, 2), "€/tCO2 par €/MWh ; bascule à 100 €/tCO2 si élec =",
      round(70 - (acier()["dri_h2_eaf"]["prix_co2_bascule"] - 100) / pente, 1), "€/MWh")
ecart = lambda p, co2: acier(p, co2)["dri_h2_eaf"]["cout_total"] - acier(p, co2)["bf_bof_ccs"]["cout_total"]
bas, haut = 10.0, 150.0                                         # dichotomie : hydrogène = captage, quota 300 €/t
for _ in range(40):
    milieu = (bas + haut) / 2
    bas, haut = (milieu, haut) if ecart(milieu, 300) < 0 else (bas, milieu)
print("quota 300 : DRI-H2 moins cher que BF-BOF + CCS sous", round(bas, 1), "€/MWh")
print(dict(zip(prix, [round(b, 1) for b in bascule])))          # la courbe, point par point
plt.plot(prix, bascule, "o-"); plt.xlabel("électricité (€/MWh)"); plt.ylabel("bascule DRI-H2 (€/tCO2)")
plt.savefig("bascule_dri_h2.png", dpi=120)

D'où vient la pente : dans l'outil, l'aciérie à l'hydrogène consomme 3,93 MWh d'électricité par tonne d'acier (hydrogène compris, champ elec_mwh) contre 0,19 pour le haut fourneau, et paie 1,70 tCO₂ de quota de moins par tonne (champ em_ets : 1,76 contre 0,06) ; (3,93 − 0,19) / 1,70 ≈ 2,2. Écrire en une phrase pourquoi un tarif d'heures creuses (cas D, cas K) change plus le verdict qu'un CAPEX d'électrolyseur.

Pièges du moteur : l'hydrogène y est en €/t (7 059 €/t = 7,06 €/kg) ; prix_co2_bascule et cout_abattement valent None pour la route de référence et pour celles qui émettent plus qu'elle (la bascule compare les émissions directes, qui paient le quota, em_ets ; le coût d'abattement compare les émissions totales, em_total) ; le moteur ne borne pas les curseurs (on peut sortir de la plage de la page) ; une hypothèse changée en mémoire le reste jusqu'au prochain modele.charger().

Partie B (N2). Refaire les prix de bascule du cas H, puis changer une hypothèse

Le cas H Cas H — À quel prix du CO₂ l'industrie française change-t-elle de procédé, et qu'est-ce qui se verrouille ? commence par là : il pose dans le moteur le prix de l'électricité (réseau compris, 6 €/MWh) et du gaz de chaque jeu de prix publié, et en tire les prix de bascule usine par usine. Il les compare ensuite à ce que fait le parc français dans le modèle pommes. Le résultat est public (economie_routes.json).

  1. Télécharger le moteur comme en partie A (dossier idr/).
  2. Lire le JSON public du cas H et garder l'acier primaire, jeu TYNDP 2026, année 2030 : quatre routes, deux tarifs (le prix moyen de l'année, electricity, et celui des 50 % d'heures les moins chères, electricity_50%_LF).
  3. Pour chaque ligne, poser l'électricité et le gaz du cas, recalculer, comparer au champ bascule : l'écart doit être nul.
  4. Expliquer pourquoi le tarif des heures les moins chères fait tomber le DRI-H₂ de 205 à 141 €/tCO₂ et l'électrolyse directe du minerai de 103 à 46, mais ne change presque pas le captage.
  5. Changer une hypothèse en mémoire : l'outil n'a qu'un prix du charbon, 80 €/t par défaut (celui du charbon vapeur) ; le porter à 220 €/t, celui du charbon à coke (commun.yaml, prix.charbon.v), et relever ce qui bouge et ce qui ne bouge pas.
import json, sys, urllib.request
sys.path.insert(0, "idr"); import modele                       # idr/ : téléchargé comme en partie A
URL = ("https://git.persee.minesparis.psl.eu/energy-alternatives/pommes_studies/pommes-case-studies"
       "/-/raw/main/H_industrie_co2/economie_routes.json")
cas = json.load(urllib.request.urlopen(URL))
lignes = [l for l in cas["routes"] if l["jeu"] == "tyndp2026" and l["annee"] == 2030 and l["produit"] == "steel_primary"]
hyp = modele.charger()
def bascules(elec, gaz, hyp=hyp):
    etat = modele.etat_defaut(hyp)
    etat["prix"]["electricite"], etat["prix"]["gaz"] = elec, gaz      # elec : tarif du cas + réseau
    return modele.calculer_produit(hyp, etat, "steel")["routes"]
for l in lignes:
    r = bascules(l["elec"], l["gaz"])[l["route"]]
    print(f"{l['tarif']:20s} {l['route']:20s} élec {l['elec']:5.1f} gaz {l['gaz']:4.1f}  cas {l['bascule']:6.1f}"
          f"  moteur {r['prix_co2_bascule']:6.1f}  écart {abs(r['prix_co2_bascule'] - l['bascule']):.1e}")
hyp["commun"]["prix"]["charbon"]["v"] = 220                     # le prix du charbon à coke, au lieu de 80 €/t
l = next(x for x in lignes if x["tarif"] == "electricity" and x["route"] == "dri_h2_eaf")
r = bascules(l["elec"], l["gaz"], hyp)
print("charbon 220 :", {k: round(r[k]["prix_co2_bascule"], 1) for k in ("bf_bof_ccs", "dri_ng_eaf", "dri_h2_eaf")})

Ce qu'il faut voir : le charbon cher rapproche toutes les routes du haut fourneau, sauf le captage, qui garde son charbon. Et le calcul usine par usine du cas H (economie_routes.py) applique le tarif des heures creuses à toute l'électricité de l'usine, four compris, alors que dans le modèle pommes du cas seule l'électrolyse achète aux heures les moins chères : une simplification à écrire dans vos limites. Le pas suivant est dans le cas H lui-même : le parc français bascule vers l'hydrogène dès 125 €/t en 2030 sous ce jeu, bien plus bas que les 205 €/t de l'usine seule. Pourquoi ? C'est la compétence suivante.

Vous l'avez compris quand…

  • Vous retrouvez la pente de 2,2 €/tCO₂ par €/MWh à partir de deux chiffres de l'outil.

  • Vous distinguez un prix de bascule (privé, une usine, un prix) d'un coût d'abattement Activité guidée — l'ordre de mérite des abattements face au quota et à la valeur Quinet.
